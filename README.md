# 家計ノート

支出・収入・投資資産(積立NISA / iDeCo)をまとめて記録できる、スマホのホーム画面に追加して使う家計簿アプリです。
データはすべて **お使いのスマホ/PCのブラウザ内(localStorage)** に保存されます。外部サーバーへの送信はありません。

## 機能

- 支出・収入の記録(金額・日付・カテゴリ・メモ)、編集・削除
- カテゴリの自由な追加・削除
- 月ごとの収支一覧・合計表示
- カテゴリ別支出の円グラフ
- 積立NISA / iDeCo の評価額を記録し、総資産・推移グラフを表示
- PWA対応(ホーム画面に追加してアプリのように利用可能)

## GitHub Pagesで公開する手順

1. このフォルダの中身(`index.html`、`style.css`、`app.js`、`manifest.json`、`service-worker.js`、`icon.svg`)を、GitHub上の自分のリポジトリにアップロードします。
2. リポジトリの `Settings` → `Pages` を開き、公開ブランチ(通常 `main`)とルートフォルダを指定して保存します。
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになります。
4. スマホのブラウザでそのURLを開き、「ホーム画面に追加」を選ぶとアプリのアイコンとして使えます。

## 注意点

- データはブラウザごとに保存されるため、**同じブラウザ・同じ端末でアクセスしないと記録は表示されません**。機種変更やブラウザの変更をすると引き継がれません。
- 複数端末での同期が必要になった場合は、クラウド保存(Firebaseなど)への切り替えが必要です。将来的に対応したくなったら、いつでも相談してください。
- ブラウザの「閲覧履歴とサイトデータを削除」を行うと、記録も消えてしまうので注意してください。
